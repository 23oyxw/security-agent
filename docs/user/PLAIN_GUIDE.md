# 通俗导读（PLAIN_GUIDE）

> **说明**: 白话概念介绍，面向非技术读者。部分页面名基于旧 Streamlit 版，v0.9.0 已切换至 Vue3（`http://<主机>:8900`），操作路径以实际界面为准。

## 一句话是什么？

这是一套跑在 **银河麒麟 / Linux** 上的 **「安全运维小助手」**：

- 能在网页里 **查风险、看监控、出报告**；
- 能用 **大模型** 回答问题、自动跑检查任务；
- 但 **不会乱删进程、乱执行危险命令** —— 关键操作都要规则把关 + 你点确认。

可以把它理解成：**会思考的安全员 + 有刹车的自动化脚本**，不是裸奔的 ChatGPT。

## 解决谁的问题？

| 谁 | 痛点 | 本系统怎么做 |
|----|------|----------------|
| 运维 / 安全员 | 进程多、不知道有没有木马 | 扫描高危进程、看端口、盯登录失败 |
| 开发人员 | Streamlit、Docker 常被误报成「黑客工具」 | 101 条校准用例，区分开发 vs 真攻击 |
| 比赛演示 / 老师 | 怕 AI 胡说 PID、端口 | 知识库 grounding + 必须引用工具结果 |
| 麒麟用户 | 双击脚本闪退、kysec 拦命令 | `打开应用.sh`、单文件 `boot_start.sh` |

## 三个典型场景（答辩可直接念）

### 场景 A：每天上班先看一眼安不安全

1. 双击 `打开应用.sh` 打开控制台  
2. 点 **安全扫描** 或侧栏 **立即扫描**  
3. 看 **总览** 的 CPU/风险数  
4. 有问题去 **进程管理** 核对，真要杀进程再勾选确认  

**白话**：像开机后的「体检报告」。

### 场景 B：怀疑被扫端口 / 被人试密码

1. 打开 **系统监控** → 启动监控  
2. 看「登录失败」「新增监听端口」「cron 变更」等事件  
3. 密码、密钥在界面上会 **自动打码**  

**白话**：像装了一个简易「门卫 + 记事本」。

### 场景 C：想让 AI 帮忙排查，但怕它瞎指挥

1. 打开 **智能助手**，问：「帮我做一次综合体检并给建议」  
2. 助手会先调扫描工具，再按知识库 **PB-*** 条目给步骤  
3. 涉及 `kill`、`sudo` 的，必须你在 **自主运维** 里勾选「允许高危」  

**白话**：AI 只能「建议 + 查数据」，不能随便「动手」。

## 核心概念（9 个词）

1. **规则引擎**：命令能不能执行，代码说了算，不是 AI 说了算。  
2. **工具**：扫描、列进程、看端口等，和 MCP 协议里的「工具」同一套（共 49 个）。  
3. **Skill**：可插拔的功能模块（5 个：健康巡检、日志分析、安全加固、配置管理、故障响应），每个自带工具、知识库、运维规则。  
4. **Agent**：会自己决定先调哪个工具；两种入口——聊天助手 / 自主运维。  
5. **告警升级**：监控发现异常后自动分级（忽略→仅通知→通知+建议→自动修复），低风险自愈，高风险通知人工。  
6. **风险演练**：不真攻击系统，用 101 条用例测规则会不会误报/漏报。  
7. **打码**：日志、聊天里出现的密码、API Key 自动变成 `***`。
8. **多模型切换**：侧栏一键切换 AI 引擎 —— MiMo（默认旗舰）、DeepSeek V3.2（跑量便宜）、DeepSeek R1（深度推理）。
9. **LiteLLM**：可选的「AI 中间件」，把所有模型统一成一个入口，自动备用切换。

### 模型怎么选？（白话版）

| 你要干啥 | 选哪个模型 | 为什么 |
|----------|-----------|--------|
| 日常问安全问题 | MiMo v2.5 Pro | 默认就用它，最聪明 |
| 快速查个进程/端口 | MiMo v2.5 | 更快更轻，回答不啰嗦 |
| 批量写一堆配置/脚本 | DeepSeek V3.2 | 便宜，量大管饱 |
| 让 AI 自己规划一个大任务 | DeepSeek R1 | 深度思考，逻辑强 |
