## P6 · 三层安全防御（60s）⬅ 核心页

```
命令输入
   ↓
L1 静态风险评估 (30%): 规则引擎 + 注入扫描
   ↓
L2 动态意图审计 (35%): LLM 交叉校验意图 vs 命令
   ↓
L3 受限执行环境 (35%): 沙箱 + 最小权限 + 备份回滚
   ↓
裁定: ALLOW / CONFIRM / APPROVE / ESCALATE / DENY
```

**演示**: `rm -rf /tmp/test` → 被拦截 (deny)
**演示**: `ls -la /tmp` → 通过 (allow, 93.25)
