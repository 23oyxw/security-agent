# 🧪 极简测试指南 — 每个页面怎么测

> 目标：5 分钟知道每个功能是否正常

---

## 1️⃣ 启动应用（每次测试前）

```bash
cd ~/security-agent
bash boot_start.sh
```
浏览器打开：`http://127.0.0.1:8501`

---

## 2️⃣ 各页面快速测试清单

### 📊 总览（打开即看）
**测什么**：系统资源、扫描状态、监控状态  
**正常表现**：
- 顶部 6 个数字：CPU、内存、磁盘有数值（如 `45%`）
- API 显示「🟢 已连接」
- 监控显示「🔴 已停止」或「🟢 运行中」
- 风险分布有图表

**一键测试**：点击「运行自检」按钮 → 等 3 秒 → 看到风险数字

---

### 🤖 自主运维（A2赛题核心）
**测什么**：自然语言 → 自动规划 → 安全执行  
**正常表现**：

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 点击「清理系统垃圾」场景按钮 | 下方输入框自动填充 |
| 2 | 不勾选「允许高危命令」 | |
| 3 | 点击「启动自主任务」 | 切换到「任务结果」页，看到步骤列表 |
| 4 | 查看结果 | 有「步骤」表格，显示执行的命令 |

**关键验证（A2赛题）**：
- 若有 `kill` 或 `sudo` 命令，应显示「⏸ 需确认」
- 回到「自主任务」页，勾选「允许高危命令」
- 点击「继续执行」→ 任务完成

---

### 🔍 安全扫描（一键扫描）
**测什么**：系统安全风险扫描  
**一键测试**：
1. 点击「立即扫描」
2. 等 5-10 秒
3. 看到「发现 X 项风险」或「未发现风险」
4. 下方有表格或「🎉 未发现风险」

---

### ⚙️ 进程管理（查看+拦截）
**测什么**：查看进程、拦截高危进程  
**一键测试**：
1. 点击「刷新」→ 看到进程列表
2. 勾选「仅高危」→ 列表变短（只显示高危进程）
3. **危险**：不要点击「执行拦截」（除非你确定要杀进程）

---

### 📡 系统监控（实时监控）
**测什么**：后台监控、告警事件  
**一键测试**：
1. 点击「启动监控」→ 看到「监控运行中」
2. 勾选「自动刷新」→ 下方数据每 5 秒更新
3. 等 10 秒，看到「心跳」事件
4. 点击「停止监控」

---

### 🧩 Skill 插件（新增强）
**测什么**：运行 Skill 工具  
**一键测试**：
1. 看到「已注册插件 5」
2. 点击任意 Skill 的「🚀 展开工具列表」
3. 点击某个工具的「运行」或「配置运行」
4. 看到执行结果（JSON 格式）

**示例**：
- healthcheck → health_full_check → 运行 → 看到系统健康报告

---

### 📚 知识库（只读浏览）
**测什么**：查看安全预案  
**一键测试**：
1. 看到「预案总数」有数字
2. 点击任意预案展开 → 看到「严重度」「预案内容」
3. 在搜索框输入「密码」→ 筛选出相关预案

---

### 💬 智能助手（对话Agent）
**测什么**：自然语言对话、工具调用  
**一键测试**：

| 测试 | 输入 | 预期 |
|------|------|------|
| 简单问答 | "你是谁" | 有回复，无工具调用 |
| 系统信息 | "查看当前进程" | 回复 + 显示「工具调用流程」 |
| 安全拦截 | 不勾选「确认高危操作」，说"杀死进程 1234" | 回复「需要用户确认」 |
| 允许执行 | 勾选「确认高危操作」，再说"杀死进程 1234" | 执行命令（如果 PID 存在） |

**关键验证**：
- 输入后，底部显示 Token 数（如 `📝 1,234 tokens`）
- 若触发 Fallback，显示 `🔄 已回退到 deepseek-v4-flash`

---

### 🔒 安全确认（当前为空）
**现状**：页面存在但功能未完整接入  
**预期**：当 Agent 执行高危操作需确认时，这里会显示待确认任务  
**当前测试**：打开应显示「✅ 当前没有待处理的确认请求」

## 3️⃣ 左侧栏状态检查

从上到下依次检查：

| 项目 | 正常显示 | 异常处理 |
|------|---------|---------|
| API 状态 | 🟢 API 已连接 | 若显示🔴，编辑 `.env` 配置 API Key |
| LiteLLM 代理 | 🟢/⚪ 代理运行中/未启用 | 若启用但异常，检查 Docker 或 `bash scripts/litellm_manager.sh start` |
| 监控状态 | 🔴/🟢 监控已停止/运行中 | |
| 告警角标 | 数字（如 `告警 3`）或隐藏 | 有数字时点「标记已读」测试 |

## 5️⃣ 常见问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| 页面打不开 | 服务没启动 | 运行 `bash boot_start.sh` |
| API 未连接 | 没配 Key | 编辑 `.env` 填入 `LLM_API_KEY=sk-...` |
| Skill 运行报错 | 工具未注册 | 刷新页面重新发现 Skill |
| 监控启动失败 | 权限不足 | 忽略，或 `sudo` 运行 |
| 告警不消失 | 未标记已读 | 点侧栏「标记已读」按钮 |
