安全运维 Agent — 离线 / 换机部署（精简包）

一、本包不含什么（正常现象）
  - data/litellm/pgdata*  → LiteLLM 的 Postgres，在目标机用 Docker 首次启动时自动创建
  - .venv                 → 目标机用 uv sync 重建
  - .env                  → 请从 .env.example 复制并填写 API Key
  - data/logs、告警库等   → 运行后自动生成

二、目标机环境
  - 【实验机】麒麟高级服务器 V11 Swan25 + LoongArch + dnf
    → 必读 docs/DEPLOY_KYLIN_LOONGARCH.md
    → 解压后: bash scripts/bootstrap-kylin-loongarch.sh
    → 勿拷贝 x86 的 .venv；LiteLLM 建议 USE_LITELLM_PROXY=false
  - 其它 Linux：Python 3.10+、uv；可选 Docker；Node 仅当需本机构建前端

三、安装步骤
  1. tar -xzf security-agent-v*.tar.gz && cd security-agent-v*
  2. cp .env.example .env   # 编辑 LLM_API_KEY、端口等
  3. 一键启动（任选其一）:
       bash start.sh              ← 推荐（首次会自动 bootstrap）
       bash 打开应用.sh           ← 麒麟桌面可双击
       bash boot_start.sh         ← 与 start.sh 相同底层
  4. 浏览器 http://<目标机IP>:8900/  默认账号见 Login 页提示
  5. 停止: bash stop.sh

四、LiteLLM（可选）
  - .env 设置 USE_LITELLM_PROXY=true 且 LLM_BASE_URL=http://127.0.0.1:4000/v1
  - boot_start 会 docker compose -f configs/docker-compose.litellm.yml up -d
  - 数据库目录会在 data/litellm/pgdata2 重新初始化，无需从旧机拷贝

五、打包命令（在开发机）
  bash scripts/package-release.sh          # 推荐：精简包
  bash scripts/package-release.sh --full   # 内网：含 .venv + .env（仍排除 pgdata）

六、验收
  bash scripts/run_regression.sh
  PYTHONPATH=. .venv/bin/python scripts/e2e_api_smoke.py
