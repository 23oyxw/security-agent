安全运维 Agent — 麒麟 LoongArch 部署说明 v0.9.0

一、两种获取方式

  方式A（推荐，需联网）：
    git clone https://gitee.com/swok/security-agent.git
    cd security-agent

  方式B（离线）：
    tar -xzf security-agent-v0.9.0-*.tar.gz
    cd security-agent-v0.9.0-*

二、安装步骤（全部在麒麟机上执行）

  1. 安装系统依赖：
     sudo dnf install -y python3 python3-pip python3-devel gcc gcc-c++ make curl

  2. 安装 uv：
     curl -LsSf https://astral.sh/uv/install.sh | sh
     export PATH="$HOME/.local/bin:$PATH"

  3. 一键初始化：
     bash scripts/bootstrap-kylin-loongarch.sh

  4. 配置 API Key：
     vi .env
     改这行：LLM_API_KEY=sk-你的密钥

  5. 启动：
     bash boot_start.sh

  6. 浏览器打开：
     http://<麒麟机IP>:8900
     账号：admin  密码：admin123

三、常见报错处理

  - "$'\r': 未找到命令"  →  git clone 拉取；或用 sed -i 's/\r$//' scripts/*.sh
  - "uv: 未找到命令"     →  export PATH="$HOME/.local/bin:$PATH"
  - "端口被占用"         →  bash boot_stop.sh
  - 防火墙无法访问       →  sudo firewall-cmd --add-port=8900/tcp --permanent

四、麒麟特有注意事项

  - 禁止拷贝 x86 的 .venv 目录（架构不兼容）
  - LiteLLM Docker 不可用（龙架构无镜像），.env 保持 USE_LITELLM_PROXY=false
  - 前端 dist/ 已含在项目中，无需在麒麟上 npm build
  - 非 root 用户可正常启动（安全沙箱权限隔离会降级，不影响功能）
